# Role

You are an expert senior software engineer and execution-focused worker agent. You are NOT the Principal Architect. Do not make high-level architectural decisions, do not branch, and do not plan. Your task is strictly limited to executing the checklist below.

# Objective

Expose the real OTA download progress (0.0–1.0 float) via the `/api/ota` status API, and update the web portal `ota.js` to use this real value instead of hardcoded percentages (50% for downloading, 85% for verifying). This aligns the portal progress bar with the hardware display, which already shows real 2%→100% progress.

# Strict Boundary Box

- **ONLY modify:** `modules/OTAUpdateManager/OTAUpdateManager.hpp`, `modules/OTAUpdateManager/OTAUpdateManager.cpp`, and `web/portal/ota.js`
- **Do NOT touch:** `lib/GithubClient/`, `platformio.ini`, or any other files
- **Do NOT touch:** any log lines or `FirmwareVersion local = ...` lines (those were WO2 and WO3)

# Line-Item Instructions

## 4a — Add `lastProgress_` member to `OTAUpdateManager.hpp`

In `modules/OTAUpdateManager/OTAUpdateManager.hpp`, find this exact line (~line 398):
```cpp
    const char*   lastOtaError_ = nullptr;             // Last error string from download engine
```

Add a new line immediately AFTER it:
```cpp
    const char*   lastOtaError_ = nullptr;             // Last error string from download engine
    float         lastProgress_ = 0.0f;                // Last progress fraction for API polling
```

## 4b — Update `publishProgress()` in `OTAUpdateManager.cpp`

In `modules/OTAUpdateManager/OTAUpdateManager.cpp`, inside `publishProgress()` (around line 766), find:
```cpp
    OTAProgressEvent event;
    event.progress = progress;
```

Replace with:
```cpp
    lastProgress_ = progress;
    OTAProgressEvent event;
    event.progress = progress;
```

## 4c — Add `progress` to status API response in `OTAUpdateManager.cpp`

In `modules/OTAUpdateManager/OTAUpdateManager.cpp`, in the status API handler (around line 1229), find:
```cpp
                    resp["ota_stack_bytes"]  = OTA_TASK_STACK_BYTES;
                    if (this->lastOtaError_) {
```

Replace with:
```cpp
                    resp["ota_stack_bytes"]  = OTA_TASK_STACK_BYTES;
                    resp["progress"]         = this->lastProgress_;
                    if (this->lastOtaError_) {
```

## 4d — Update `ota.js` progress bar — downloading state

In `web/portal/ota.js`, inside `pollOtaStatus()` (around line 339), find:
```javascript
      let pct = 0, label = state, barColor = 'var(--primary)';

      switch (state) {
        case 'downloading':
          pct = 50; label = 'Downloading firmware...';
```

Replace with:
```javascript
      let pct = Math.round((response.progress || 0) * 100);
      let label = state, barColor = 'var(--primary)';

      switch (state) {
        case 'downloading':
          label = 'Downloading firmware...';
```

## 4e — Update `ota.js` progress bar — verifying state

        case 'verifying':

   its row.

     overwrites the next.

     boards. Legacy gets it through an `AppFonts` addition or a local font choice for row 2; pick
     the smallest change that does not alter other boards' fonts.

     pixels it adds.

**Legacy** (`DrawingPrimitives.cpp`, `DiagnosticsBoard.{hpp,cpp}`, `Fonts.hpp`):
- *Clip.* `setClipWindow` now gets `x + w` and `y + h` (exclusive far corner, `u8g2.h:352/354`); the validity test is

- *Height, measured.* The row height does **not** contain the descender tips: under `setFontRefHeightAll` +
  `setFontPosTop` a font's lit rows run `y+1 .. y + getMaxCharHeight()` inclusive (11, 17 and 13 for the three
  fonts; `EVIDENCE.md` 1b has the table), one more than `getMaxCharHeight()` counts. The board passes explicit
  heights 18, 14, 12, 12 (`getMaxCharHeight() + 1`) instead of `-1`. I did not change `drawText()`'s `h == -1`
  default, which would also change `SystemMessageWidget` (out of scope; see the finding below). The text sits
  where it did, since `(height - (ascent - descent)) / 2` is 0.
- *Separator.* New `AppFonts::defaultSmallLatin1()` (`u8g2_font_helvR08_tf`; native returns `nullptr`) for row 2
  only; the format strings use `"\xC2\xB7"`. **Rendered: yes, 2 lit pixels** (`separator_probe.json`). Row 2's text
  now sits two pixel rows lower (ascent 11 against 9), hence its height 14.
- *Truncation.* `setTruncated(true)` on rows 2 to 4. It renders correctly: `long_ssid` ends `...10.1...` inside the row.
  Also fixed: the trim removed one **byte** at a time and, with the text now UTF-8, a cut on the separator left a
  lone lead byte that U8G2 draws as a stray glyph. It now removes whole characters (oracle check over 189 widths:
  0 mismatches; the old trim: 14). Scratch program, not committed.

**Rows do not overlap.** Lit rows, in every scenario: 2..17, 20..29, 32..41, 46..55 (row 2 is 20..27 without a

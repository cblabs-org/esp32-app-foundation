# WO2 — Integrate Re-Exported UI C + Enable Fonts

### Role Definition
> You are an expert senior software engineer and execution-focused worker agent. You are NOT the Principal Architect. Do not make high-level architectural decisions, do not branch, and do not plan. Your task is strictly limited to executing the checklist below.

## Objective
Replace the generated LVGL UI code in `modules/LVGLDisplay/ui/` with a fresh SquareLine
"Export UI Files" of the reviewed project, swap the compiled boot-logo asset, and enable
the fonts the new design requires — so `crowpanel-128-rotary` compiles against the new UI.
Do **not** modify the C++ bridge yet — that is WO3 (a broken bridge here is expected).

## ⚠️ Precondition (BLOCKING — do not start until satisfied)
This WO needs a **fresh SquareLine Studio "Export UI Files"** of the revised project.
Agents cannot run the SquareLine GUI. Before you begin, the exported tree must already be
present in `modules/LVGLDisplay/ui/` (the human runs *Export → Export UI Files* in
SquareLine Studio 1.6.1, export path `modules/LVGLDisplay/ui/`). If the `ui/` tree still
shows the OLD symbol set (e.g. `ui_ui_DiagTitle`, `ui_uiSystemWizardGroup`, or
`ui_img_cblabs_320x100_png.c`), **STOP and report** — the precondition is unmet.

Confirm the export is present by checking the new symbol set exists, e.g.:
`grep -l uiSystemSetupGroup modules/LVGLDisplay/ui/ui_uiSystemScreen.c`
and that `modules/LVGLDisplay/ui/ui_img_cblabs_180x58_png.c` exists.

## Context
- **Branch:** `sls-screen-redesign/wo2-integrate-ui-export` (based on WO1).
- Current fonts enabled in `modules/LVGLDisplay/lv_conf.h`: montserrat **10, 14, 16, 20, 28**
  (default `montserrat_14`).
- New design uses montserrat **12, 14, 16, 18, 20, 22, 40** — so **12, 18, 22, 40 must be enabled**;
  10 and 28 become unused (see checklist for prune decision).
- Old logo asset C: `ui_img_cblabs_320x100_png.c`; new: `ui_img_cblabs_180x58_png.c`
  (both `ui.h` `LV_IMG_DECLARE` and `filelist.txt` are regenerated by the export).
